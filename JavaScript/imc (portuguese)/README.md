# simple BMI calculator pt-BR 

A BMI JavaScript file.

## Functions

- Calculate BMI number using user input.
- 6 BMI classification (in portuguese).

## How it works.

The program asks your height (in meters) and weight (in kilograms). Later the program calculate your IMC using the formula *(weight / (height * height))* and print the result with a classification based in your result.

## How to run.
1. Place `index.html` and `imc.js` at the same folder;
2. Open `index.html` in a web browser;
3. The program executes via browser prompts on terminal.
