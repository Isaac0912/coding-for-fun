# Russian Roulette Game

A simple browser-based Russian Roulette game built using JavaScript, using a `while` loop and `alert/prompt` for interaction.

## How it works

The game randomly selects a number between 1 and 6. The player must guess a number in the same range. If the chosen number matches the "bullet number", the player loses.

## How to run

1. Place `index.html` and `russianroulette.js` in the same folder;
2. Open `index.html` in a web browser;
3. The game will start automatically via browser alerts and prompts.

## Controls

- Enter a number between 1 and 6 to play.
- Click **Cancel**, enter `2` in the "play again" alert or enter `0` (if supported by your version) to exit the game.
