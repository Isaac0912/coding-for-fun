# Cinema tickets (pt-BR)

An simple code of tickets using if, else, else if, while, console.log and variables.

## How it works.

The program asks your ticket preference (number `1` for full-price ticket or number `2` for half-price ticket), your age and if you have a student ID. If you chose half-price ticket but don't have student ID neither age below 18, you don't have the conditions to pay for half-pricew ticket. But if you have conditions or chose full-price ticket, you are authorized.

## How to run.

1. Place `index.html` with js folder that contains `ingresso.js`;
2. Open `index.html` in a web browser;
3. The progra will execute in browser terminal.
